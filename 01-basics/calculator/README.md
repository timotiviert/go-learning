# Calculator

Erstelle einen CLI Calculator mit:
- Addition, Subtraktion, Multiplikation, Division
- Fehlerbehandlung (Division durch 0)
- Command-line Flags (flag package)
- Ergebnis in Datei schreiben (os package)


## Usage
```
main.go <a> <operand> <b>
```
`a` and `b` must be numbers and `operand` one of:

- `+`: Addition
- `-`: Substraction
- `x`: Multiplication (the letter x as `*` is a placeholder in UNIX)
- `/`: Division
